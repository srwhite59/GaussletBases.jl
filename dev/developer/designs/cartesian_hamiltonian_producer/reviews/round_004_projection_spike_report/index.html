Design Findings

  • The same terminal retained/support/transform record shape is usable for one-center, H2, and Cr2.
  • One-center still required the old skeleton route-shape input to reach terminal records; this must be clarified before freezing Slice A.
  • Previous-block projection appeared numerically stable in this spike.
  • Raw cross-overlaps were already small and projected overlaps dropped to roundoff.
  • All PQS shell ranks stayed at the expected 98.
  • Effective support growth was modest in this approximation: each PQS shell stayed at its own support size.
  • The spike used existing shell-local coefficients for previous PQS blocks, not fully recursively expanded projected coefficients. Production Slice A still needs the true accumulated-coefficient/support audit.
  • Dense scratch projection was already a 75 s Cr2 spike, so production Slice A should use factorized or incremental overlap construction.
