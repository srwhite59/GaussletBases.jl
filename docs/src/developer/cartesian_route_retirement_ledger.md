# Cartesian Route Retirement Ledger

This is a compact cleanup index, not source authority or a future architecture
plan. Machine authority and exact deletion contracts live under the
[Cartesian Hamiltonian producer design index](designs/cartesian_hamiltonian_producer/README.md).
Git history preserves the earlier development-era classifications and measured
oracle details.

## Current Route Boundary

The live producer follows:

```text
parent and common shellification
-> terminal lowering and retained contracts
-> PQS or White-Lindsey terminal realization
-> exact one-body and IDA assembly
-> optional residual/supplement composition
```

The former replacement story ending in `CartesianUnitPairs`,
`CartesianPairOperatorPlans`, and broad
`CartesianPairBlockMaterialization` is abandoned. It is not the destination
for current route work.

## Rules For Future Cleanup

1. Prove committed callers, exports, load-time effects, serialization, and
   artifact ownership before requesting deletion.
2. Prefer deleting an orphaned surface and its test pressure over introducing
   an adapter.
3. Preserve active numerical kernels even when an abandoned wrapper once used
   them.
4. Validate current endpoints, not the vocabulary of the retired route.
5. Treat ignored probes and old reports as historical evidence, not
   compatibility obligations.
6. Require a new docs-only amendment before restoring any retired API.
